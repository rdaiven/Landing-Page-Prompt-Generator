# Landing Page Prompt Generator

An interactive "Copy Workbench" for generating conversion-focused landing page prompts. Built with React and Tailwind CSS.

## Overview
This tool helps medical aesthetic clinics (and other businesses) structure their landing page content using proven conversion frameworks. It provides a visual interface to input content, select layouts for each section, and generate a structured prompt for AI coding assistants to build the final high-fidelity website.

## Features
- **Visual Workbench**: 3-panel interface (Sidebar, Editor, Preview).
- **Section Management**: Enable/disable sections, reorder (coming soon), and track progress.
- **Layout Selection**: Choose from multiple pre-defined layouts for headers, hero sections, testimonials, etc.
- **Real-time Preview**: See a wireframe representation of your landing page update instantly.
- **Global Configuration**: Set brand identity, color palettes, and typography.
- **Prompt Generation**: Export a detailed, structured prompt ready for LLM consumption.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/landing-page-prompt-generator.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd prompt-generator
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Application

Start the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
